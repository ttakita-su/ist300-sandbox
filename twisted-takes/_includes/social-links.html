{%- comment -%} Links to the configured social platforms. Platforms with no URL are skipped. Parameters (all optional): links a hash with instagram / tiktok / youtube keys, e.g. a genre's discussion_links. Empty entries fall back to the profile URLs in _config.yml (site.social). verb text before the platform name, e.g. "Follow on" or "Discuss on". class extra class for the list. Outputs nothing at all when no platform has a URL, so callers can capture it and test `contains "{% if include.verb %}{{ include.verb }} {% endif %}{{ sl_name }} {%- endif -%} {%- endfor -%} {%- endcapture -%} {%- if sl_items contains "{{ sl_items }} {%- endif -%}
